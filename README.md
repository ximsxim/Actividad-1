# Actividad-1
Repositorio para la actividad 1
En este ejercicio se solicitó implementar estructuras de datos de pilas y colas utilizando listas ligadas en Java, simulando un sistema operativo básico que gestiona comandos y procesos. Se trabajó con las clases Node, LinkedList, Stack, Queue y Main.

Cómo Compilar el programa

En la terminal, ubicarse en la carpeta raíz del proyecto (Actividad-1) y ejecutar el siguiente comando:

javac -d bin src/listas/*.java


-d bin → indica que los compilados van a la carpeta bin.

src/listas/*.java → compila todas las clases que están en el paquete listas (Node, LinkedList, Stack, Queue y Main).

Cómo Ejecutar el programa

En la terminal, desde la carpeta raíz del proyecto (Actividad-1), ejecutar el siguiente comando:

java -cp bin listas.Main


-cp bin → indica que se usarán todas las clases compiladas que están en la carpeta bin.

listas.Main → ejecuta la clase Main que se encuentra en el paquete listas.
